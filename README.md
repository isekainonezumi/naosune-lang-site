# ナオスネ語(Naosunefev)紹介サイト

パルミキワ・ロディヴガロ世界のナオスネ共和国で話される人工言語「ナオスネ語(Naosunefev)」を、作者本人(異世界のネズミ)が紹介する静的サイトです。

- 言語の作者: 異世界のネズミ(このリポジトリの管理者)
- 辞書データ公開ツール: [ZpDIC Online](https://zpdic.ziphil.com/dictionary/Naosunefev)(開発: Ziphil氏)

## ページ構成

| ファイル | 内容 |
|---|---|
| `index.html` | 概要・世界観の紹介 |
| `phonology.html` | 文字・発音の紹介 |
| `grammar.html` | 文法解説 |
| `translations.html` | 翻訳集(名言・標語・基礎語彙) |

## ローカルでの確認方法

Node.jsなどの環境がなくても、`index.html`をブラウザで直接開けば確認できます。
簡易サーバーを使う場合は例えば:

```bash
python3 -m http.server 8000
```

としてから `http://localhost:8000` を開いてください。
